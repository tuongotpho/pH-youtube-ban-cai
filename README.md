# pH-youtube — bản cài đặt

Lướt YouTube **không quảng cáo** và **tải video / Shorts / playlist / MP3** bằng một nút. Ứng dụng Windows miễn phí.

- Trang giới thiệu và tải: https://ph-media.web.app
- Tải bản mới nhất: [pH-youtube-Setup.exe](https://github.com/tuongotpho/pH-youtube-ban-cai/releases/latest/download/pH-youtube-Setup.exe)

Kho này chỉ chứa bản cài đặt đã đóng gói (không chứa mã nguồn).

Yêu cầu: Windows 10/11 64-bit, Microsoft Edge WebView2 Runtime (Windows 11 có sẵn).

Thành phần đi kèm và giấy phép: uBlock Origin (GPLv3), FFmpeg (GPLv3, bản gyan.dev), yt-dlp (Unlicense), Microsoft WebView2 SDK. Chi tiết và link mã nguồn trong tệp `GIAY-PHEP-THANH-PHAN.txt` của bộ cài.
